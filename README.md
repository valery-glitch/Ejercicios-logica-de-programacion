# 💻 72 Ejercicios de Lógica de Programación

## 📌 Descripción

Este proyecto consiste en una colección de 72 ejercicios prácticos de lógica de programación, desarrollados con el propósito de fortalecer el pensamiento lógico, el análisis de problemas y las habilidades de programación.

Cada ejercicio representa un reto que permite aplicar conceptos fundamentales de programación y desarrollar habilidades para encontrar soluciones mediante código.

## 🎯 Objetivo

Fortalecer las habilidades de razonamiento lógico y resolución de problemas mediante la práctica de diferentes ejercicios de programación.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 📚 Contenido del proyecto

El proyecto reúne 72 ejercicios de lógica de programación que permiten practicar y reforzar diferentes conceptos fundamentales del desarrollo de software.

Entre sus objetivos de aprendizaje se encuentran:

- Desarrollo del pensamiento lógico.
- Análisis y solución de problemas.
- Aplicación de estructuras de programación.
- Fortalecimiento de habilidades de codificación.

## 🚀 Ejecución del proyecto

Para visualizar la página localmente:

1. Clonar o descargar este repositorio.
2. Ubicar los archivos del proyecto en una carpeta local.
3. Abrir el archivo `index.html` en un navegador web.
